纯 Web 版原理说明：
这个版本没有使用任何前端技术（无 Vue、无 HTMX、无 AJAX）。
点击「切换」「编辑」「删除」时，浏览器发送普通的 HTTP 请求，服务器处理后重定向回首页，
浏览器整页刷新显示新内容。
这就是 ASP Classic / PHP 时代最原始的 Web 交互方式。
可对比 app-1 (HTMX 版) 体验「局部刷新」带来的差异。
