## app1 - 双 UI 架构合并

- 将 `app/` (Vue.js JSON API) 和 `app-1/` (HTMX HTML) 合并为一个 FastAPI 应用
- **目录结构**：`core/`(共享:config/database/models/schemas/services) + `routers/api/`(JSON) + `routers/web/`(HTML)
- **URL 设计**：`/`(Vue外部) + `/internal`(HTMX内部) + `/api/todos`(JSON) + `/todos`(HTML片段)
- **services.py**：从两个 router 抽离的纯业务逻辑函数（get_all, get_by_id, create, update_info, toggle_status, delete）
- **数据库**：合并为同一个 `todo.db`（原两个项目用不同 DB 是为了教学隔离）
- **样式**：两个 style.css 合并为一份
- **Import 注意**：`routers/api/` 和 `routers/web/` 用 `...core` 引用共享层
- **启动**：`"C:\Users\jeffr\anaconda3\python.exe" -m uvicorn app1.main:app --host 0.0.0.0 --port 8005 --reload`
- **原项目未动**：`app/` 和 `app-1/` 保持不变
- **认证**：暂未实现（用户说晚点从长计议）
- **数据库改名**：从 `todo.db` 改为 `todo_api.db`，放在项目根目录（与 `todo.db`、`todo-1.db` 平级）
- **路径健壮性**：模板和静态文件路径改为 `Path(__file__).resolve().parent / "xxx"` 绝对路径写法，不依赖工作目录
