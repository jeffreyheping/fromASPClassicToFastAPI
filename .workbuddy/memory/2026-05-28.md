## app-1 (HTMX 版) 启动配置

- **启动命令**：`cd 项目目录 && "C:\Users\jeffr\anaconda3\python.exe" -m uvicorn "app-1.main:app" --host 0.0.0.0 --port 8003 --reload`
- **注意引号**：`app-1` 含连字符，命令行需加引号 `"app-1.main:app"`
- **踩坑1**：Anaconda 装了错误的 `multipart` 包，需替换为 `python-multipart`（Form 表单依赖）
  - `pip uninstall multipart -y && pip install python-multipart`
- **踩坑2**：`app-1/static` 目录不存在，需手动创建 `mkdir app-1/static`
- **访问地址**：http://localhost:8003/
